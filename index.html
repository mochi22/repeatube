What is RepeaTube?

RepeaTube is a free online tool to repeat any YouTube video. Paste a YouTube URL to get started — then set an A-B loop at any point in the video. Perfect for learning languages, practicing music, studying sports techniques, or any skill that benefits from focused repetition.

Features

  • Select any YouTube video by pasting the URL
  • Repeat a full video or any section in an infinite loop
  • Set A-B loop points with buttons or the dual-handle slider
  • Change playback speed with the speed control buttons
  • Toggle subtitles and switch caption language
